**Frequency-Tagged Analysis (FTA) plugin for Brainstorm**

`bst_fta` is a [Brainstorm](https://neuroimage.usc.edu/brainstorm/) plugin for analysing frequency-tagged responses. It provides tools for processing, analysing, and visualising FTA data within the Brainstorm environment.

**Overview**

Frequency-tagged analysis (FTA) is an approach for studying neural responses to stimuli that are presented with a known temporal periodicity. By tagging stimulus features at specific frequencies, their corresponding neural responses can be identified and quantified in electrophysiological or neuroimaging data.

`bst_fta` integrates FTA workflows into Brainstorm, allowing frequency-tagged responses to be analysed alongside the existing Brainstorm source- and sensor-level visualisation tools.
